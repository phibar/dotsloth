Add `dotsloth ui`: a local web interface for everything dotsloth does - dashboard and sync, organizations and cloning, a validated config editor, Keychain secrets, env files, doctor, Mail, Claude Code and the periodic sync. It listens on 127.0.0.1 only, signs the browser in through a link with a random token, and refuses foreign hosts and origins.
